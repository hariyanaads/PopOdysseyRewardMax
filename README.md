# Pop Odyssey Reward Max

Xposed module untuk memaksimalkan reward iklan di Pop Odyssey.

## Download

Download APK dari [Releases](../../releases)

## Cara Install

1. Install APK module ini
2. Buka LSPosed / EdXposed
3. Aktifkan module, pilih scope "Pop Odyssey"
4. Reboot device
5. Buka Pop Odyssey dan nikmati reward maksimum!

## Fitur

- ✅ Max reward 999999 setiap iklan
- ✅ Support AppLovin MAX, AnyThink, Pangle, Vungle, dll
- ✅ Auto-trigger reward
- ✅ Bypass check iklan ready
